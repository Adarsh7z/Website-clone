# Sartorial Atelier — Website Clone

A high-fidelity responsive clone of the modern bespoke menswear storefront design, built with **React**, **TypeScript**, **Tailwind CSS**, **JSON**, and **GSAP 3**.

## Features

- **Hero Carousel**: Full-bleed luxury editorial carousel with smooth GSAP Ken Burns scale and crossfade transitions, autoplay controls, and floating slide previews.
- **Brushed Metallic Silver Typography**: Custom `.type-silver` and `.type-silver-dark` text gradients with specular sheen highlights.
- **Continuous Marquee Band**: Infinite GSAP loop displaying brand hallmarks with pause-on-hover.
- **Curated Collections Grid**: 3-column interactive layout for *Office Casuals*, *Blazers & Suiting*, and *Festive Kurta Sets*.
- **Selected Rail (Features)**: Category filter tabs, responsive product cards, fabric indicators, and price tags.
- **Craftsmanship & Step-by-Step Flow**: Highlights on natural textiles, complimentary alteration, and 3-step WhatsApp ordering.
- **Atelier Story**: Editorial split dark-mode section featuring workshop photography and craftsmanship narrative.
- **Voices of Distinction**: Editorial customer testimonials with star ratings.
- **Transparent Pricing & Bespoke Packages**: Ready-to-Wear, Made-to-Measure Suiting, and Festive Couture tiers.
- **Visit the Store & Interactive Map**: Atelier address, hours, contact, and grayscale OpenStreetMap embed matching the original design.
- **Live Search Modal**: Real-time product search with keyboard shortcut navigation.
- **Quick View Modal**: Interactive sizing, colour selectors, craftsmanship breakdown, and WhatsApp order generator.
- **Floating Concierge & Drawer Menu**: Responsive navigation drawer and floating WhatsApp contact button.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** (Build tool & dev server)
- **Tailwind CSS** (Design system tokens & responsive layouts)
- **GSAP 3** + **@gsap/react** (ScrollTrigger, smooth timelines, staggers, and reduced-motion support)
- **Lucide Icons & Custom SVG**

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
